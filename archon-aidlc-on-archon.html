The ideasteps 1–2 · what each tool does, and how one maps onto the other
1
why

Two tools, one lifecycle

AI-DLC says which stages a piece of work goes through. Archon runs a process written as a graph. Put together: AI-DLC's stages, run by Archon.

read · 2 min

AWS AI-DLC (the AI-Driven Development Lifecycle, run with AI-DLC Workflows 2.11) splits work into 33 stages in five phases: set up, think about the idea (Ideation), decide exactly what to build (Inception), build it (Construction), run it (Operation). An AI persona leads each stage (product manager, architect, developer, QA lead …), a person approves each stage at a gate, and a scope decides how many stages run, from 8 for a proof of concept to all 33 for a feature.

Archon runs any process you write as a graph of nodes, with a pause wherever a person decides. This page writes AI-DLC's lifecycle as one Archon workflow, aidlc-on-archon, and checks it with Archon: it validates, and in 13 dry runs Archon ran exactly the stages each AI-DLC scope lists.

In plain words. AI-DLC is the recipe book: which courses a meal has and who signs off each one. Archon is the kitchen's ticket rail: it calls the next course, holds it until the chef says yes, and keeps the tickets. This page puts the recipe book on the rail.
New to AI-DLC? The AI-DLC course runs the real engine. New to Archon? Start with the introduction.

In plain words. Every stage has the same shape in Archon: an agent writes, a person approves. The only exceptions are the three setup stages, which have no gate in AI-DLC either, and Code Generation, which runs the tests between the two.

7
honest limits

What's the same, and what isn't

The workflow runs AI-DLC's stages and gates. It is not AI-DLC's engine.

read · 2 min
AI-DLC's engineaidlc-on-archon
Stages, phases, gates33, 5, a gate after each stage after setupthe same 33, 5 and 30 gates
Which stages rundecided by the engine from the scope, and re-planned as it goesfixed when the run starts: the scope list and two rules
Personas14 agent files with full instructions; support agents and two senior reviewers join in bigger scopesa role named in each stage's prompt; one agent per stage
Mob mode (2.4 User Stories)several personas work on one draftone agent asked to weigh their views (could be parallel nodes and a merge node)
The recordaidlc-docs/, an audit log, a state file the next session readsthe run's artifacts, transcript and cost in ~/.archon
Pausing and resumingthe session stops at a gate; you answer in Claude Codea durable wait: answer later with archon workflow approve, the Web UI or chat
Run with a modelyes, in the AI-DLC coursenot yet: validated and dry-run only
Use AI-DLC when you want its full method and record. Use this workflow when your team already runs Archon and wants AI-DLC's stages and sign-offs in it, or wants to cut the lifecycle down to the stages it actually uses.

Where this comes from

AI-DLC's 33 stages, their phases, lead and support personas and modes, and the 11 scope lists are AI-DLC Workflows 2.11's own tables (aidlc engine gen stage-table and gen scope-table), copied from the AI-DLC course into tools/data/aidlc/. The personas' short roles and each stage's one-line job are this course's words. The workflow and its script are generated by tools/make_aidlc_workflow.py. Every Archon output on the page is real, from Archon 0.13.2 on Windows (5 Nov 2026), captured by tools/capture_aidlc_map.py in a copy of the course's java workspace. No real (model) run of this workflow has been done; items marked documented were not run.
