Run it yourself

  1. Set up Archon as on the setup page (steps 1–4), with JDK 21, Maven and Git Bash.
  2. Take the workspace from the course repo: archon-hello-world-java/multirepo-workspace/ holds the team's files and both repos as they are after the run (library 1.0.1, API 1.2.1). To start where the run started, do steps 1–4 instead: they build the two repos from the public starter at v1.1.0 (the course's tools/setup_multirepo_run.py runs exactly those commands).
  3. Make each folder a git repo with a remote (steps 2–4), and run archon workflow run fix-across-repos --folder … from the workspace root.
  4. Answer the two waits. Check the plan's numbers: the course's plan miscounted two of them.
Your run id, times, cost and commit hashes will differ. The course's transcript is in archon-hello-world-java/multirepo-run/logs/, its artifacts in multirepo-run/artifacts/, each repo's diff in multirepo-run/git/.
